# Security policy

Report a vulnerability privately to **deepfieldstudios@gmail.com** with "SECURITY" in the
subject, or through GitHub's private vulnerability reporting on this repository. Please do
not open a public issue for security problems.

You will get an acknowledgement within 5 working days. Fixes for confirmed issues are
released as a new version, and the reporter is credited unless they prefer not to be.

Supported versions: the latest commit on `main`.
